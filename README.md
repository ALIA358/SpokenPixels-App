# SpokenPixels App
SpokenPixels is a Deaf Accessibility Mobile App Prototype designed in Figma.
# Features
- Video content with subtitles
- Sign language interpreter support
- Tap to Speak (Speech to Text)
- Accessibility settings
- Help and support options
- User-friendly navigation
# Tool Used
Figma (UI/UX Design)
